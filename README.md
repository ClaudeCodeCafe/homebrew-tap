# ClaudeCodeCafe Homebrew Tap

Homebrew formulae for [ClaudeCodeCafe](https://github.com/ClaudeCodeCafe) tools.

## Install

```bash
brew tap ClaudeCodeCafe/tap
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| [vshot](https://github.com/ClaudeCodeCafe/vshot) | Video frame extraction for AI |

### vshot

```bash
brew install vshot
```
